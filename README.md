🚖 Ride Booking System in C++

A console-based ride booking application built in C++ that simulates an Uber/Ola-like system with multiple vehicle types, driver availability, ride history, and fare calculation.

📌 Features

🔹 Multiple Vehicle Support – Car, Bike, and Auto with different fare rates.

🔹 Driver Management – Tracks drivers’ availability and assigns nearest driver based on vehicle type.

🔹 Ride Booking – Users can book rides between predefined cities.

🔹 Fare Calculation – Dynamically calculates fare based on distance and vehicle type.

🔹 Ride History – Stores past rides in a text file (RideHistory.txt) for persistence.

🔹 Ride Completion – Drivers become available again once a ride is completed.

🛠️ Tech Stack

Language: C++ (OOP-based design)

Concepts Used:

Classes & Objects

Inheritance & Polymorphism

File Handling (fstream)

STL (vector, map)
